## Classes

1. Linked List - Stores items in order using nodes. It has a head and tail to make adding items easier.

2. Hash Tables - Stores information using keys and values. It uses buckets and linked lists to handle stored data.

3. BST - Stores station names in order. Smaller values go left and larger values go right.

4. MinHeap - Stores tasks by priority. The lowest priority number comes out first.

5. Graph - Stores stations and their connections. It uses a HashTable and LinkedLists to keep track of connected stations.

6. LinkedStack - Stores navigation history. It uses a LinkedList and removes the newest item first.

7. LinkedQueue - Stores passengers waiting in line. It uses a LinkedList and serves the first person who arrived.

8. HashSet - Stores unique station names. It uses a HashTable and supports combining and comparing groups of stations.
